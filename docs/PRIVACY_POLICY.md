# Privacy Policy

Effective date: 2026-06-11

Watch Later Manager for YouTube runs locally in your browser on YouTube playlist pages.

The extension reads the visible Watch Later page only so it can add selection checkboxes, sort visible rows by watched progress, and click the visible remove action for selected rows.

The extension does not collect, store, sell, share, or transmit personal data. It does not use the YouTube API, private YouTube requests, cookies, tokens, account credentials, analytics, ads, or external servers.

Data sharing: none.

For support, use the support contact listed on the Chrome Web Store item.
