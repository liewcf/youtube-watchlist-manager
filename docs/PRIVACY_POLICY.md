# Privacy Policy

Effective date: 2026-06-11

This policy explains how the Watch Later Manager for YouTube Chrome extension handles data. The content script loads on YouTube pages so it can handle YouTube single-page navigation, and its toolbar activates locally in your browser only on YouTube Watch Later playlist pages.

## Single purpose

The extension helps you clean up the visible YouTube Watch Later playlist page by adding selection checkboxes, watched-first visual sorting, and bulk removal controls.

## Data handled locally

The extension processes visible page content on the Watch Later page only. This can include visible video rows, video titles, watched progress indicators, menu buttons, menu item text, and the checkbox selections you make in the page.

This data is used only in your browser to show the toolbar, update selected counts, visually sort loaded rows, and click YouTube's visible remove action for selected rows.

## Data collection and transfer

The developer does not collect, receive, store, sell, share, or transmit your Watch Later data, browsing activity, account data, or personal information.

The extension does not send page content or user activity to the developer or to any external server.

## Limited use

Any data handled by the extension is used only to provide or improve its single user-facing purpose: managing the visible Watch Later page. The data is not used for advertising, analytics, credit checks, profiling, resale, or any unrelated purpose.

No human can read your Watch Later data through this extension because that data is not sent to us.

## Retention and deletion

The extension does not create an account, database, server log, analytics profile, or cloud backup. It does not store your Watch Later data. Temporary page state, such as selected checkboxes and visual sorting, exists only in the current browser page and is cleared when the page is reloaded or closed.

## Permissions and scope

The extension does not request Chrome API permissions. Its content script loads on YouTube pages so it can handle YouTube single-page navigation, but it activates only on the Watch Later playlist.

## What the extension does not use

- YouTube API calls
- Private YouTube requests
- Cookies, tokens, or account credentials
- Analytics, ads, or external servers
- Remote code

## Data sharing

None.
